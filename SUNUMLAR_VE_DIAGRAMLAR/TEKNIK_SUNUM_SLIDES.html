Türkçe KÜB Tabanlı Klinik Karar Destek Sistemi

Tarih: 2026-04-10 | Versiyon: v1.0

1. Proje Özeti

  • Nedir: Türkçe KÜB PDF'lerini işleyen RAG-based CDSS
  • Amaç: Çoklu ilaç etkileşimi ve kontrendikasyon riskini tespit
  • Teknik: ChromaDB (vector) + Neo4j (graph) + Claude Haiku (LLM)
  • Durum: Dalga 2 tamamlandı (60 ilaç, 1036 chunks)

3. 11 Adımlı Query Pipeline

  1. Hasta Profili: Yaş, cinsiyet, lab değerleri
  2. Sorgu Tipi: Kontrendikasyon/etkileşim/doz
  3. Section Filtering: Sorgu tipine uygun KÜB bölümleri
  4. ChromaDB Retrieval: k=8+4 chunks
  5. Cross-Encoder Reranking: Top-8 relevance
  6. Neo4j Graph: Drug-drug relationships
  7. Kümülatif Risk: 9 kategori analiz
  8. CYP450 Mapping: Enzyme interactions
  9. LLM Prompt: MUTLAK KURAL guardrail
  10. Inference: Claude Haiku (temperature=0)
  11. Validation: "Güvenlidir" yasağı + kontrol

3a. Adımlar 1-5: Retrieval

Adım 1-2: Hasta profili alınır, sorgu tipi otomatik tespit edilir

Adım 3: Sorgu tipi (örn: "kontrendikasyon") → bölüm (4.3)

Adım 4: ChromaDB'de filtrelenmiş arama (metadata filter)

Adım 5: 12 chunk'dan top-8 cross-encoder ile seçilir

Latency: 150ms (retrieval) + 50ms (reranking) = 200ms

3b. Adımlar 6-8: Analysis

Adım 6: Neo4j'den seçili ilaçlar arası relationships

Adım 7: 9 kategori risk: ADR overlap, böbrek, karaciğer, CYP450, polifarmasi vb

Adım 8: CYP450 profili: substrate-inhibitor-inducer mapping

Latency: 200ms (Neo4j) + 50ms (risk) + 30ms (CYP) = 280ms

3c. Adımlar 9-11: LLM + Validation

Adım 9: ChromaDB + Neo4j + CYP450 bilgileri bağlama format edilir

Adım 9: MUTLAK KURAL prompt: "Bağlamda olmayan yazma"

Adım 10: Claude Haiku API call (800ms)

Adım 11: 3 guardrail: "güvenlidir" yasağı, ilaç adı validasyonu, token limiti

Total Latency: ~2.1 sec | Cost: $0.009

4a. Neden v1 (0.40) Başarısız Oldu?

  1. Dar Corpus: 4 ilaç, 200 chunk → LLM eğitim verisinden dolduruyor
  2. Prompt Guardrail Yok: LLM "güvenlidir" yazabiliyor
  3. Retrieval Gürültüsü: Alakasız chunks (raf ömrü vb) geliyor
  4. Section Filtering Yok: Sorgu tipiyle eşleşmeyen bölümler aranıyor

Çıktı: LLM çok serbest, hallüsinasyon yüksek

4b. Neden v2 (0.78) Başarılı Oldu?

  1. KÜB Genişlemesi: 60 ilaç, 1036 chunks (ilgili bilgi var)
  2. Section-Based Filtering: Sorgu tipi → bölüm mapping
  3. Cross-Encoder Reranking: Top-8 most relevant
  4. MUTLAK KURAL Prompt: "Bağlamda olmayan yazma" açık kural
  5. "Güvenlidir" Yasağı: Regex + output validation

Çıktı: KÜB'ye sadık, guardrail uyumlu, minimal hallüsinasyon
