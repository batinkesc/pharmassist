# Sunumlar ve Diyagramlar

Proje sunumu, teknik diyagramlar ve görselleştirmelerin yer aldığı klasör.

## Dosyalar

### 📊 Sunumlar

- **TEKNIK_SUNUM.md** — Markdown formatında teknik sunum (61 KB)
  - Proje mimarisi, teknoloji stack'i, sistem bileşenleri detaylı açıklaması
  - Stakeholder ve klinisyen sunumları için temel kaynak
  
- **TEKNIK_SUNUM_SLIDES.html** — HTML formatında sunum slides (15 KB)
  - Web tarayıcısında açılabilir
  - TEKNIK_SUNUM.md'nin interaktif HTML versiyonu
  - Presentations için hazır format

### 🔄 Diyagramlar

- **DIAGRAMLAR_VISUALIZATION.html** — Sistem mimarisi görselleştirmesi (26 KB)
  - Pipeline akışı
  - Komponent ilişkileri
  - Data flow diagramları
  - Web tarayıcısında interaktif görüntüleme

- **ACTIVITY_DIAGRAM.md** — Aktivite diyagramı (8.8 KB)
  - Klinisyen-sistem etkileşimi
  - Sorgulama sürecinin adım adım akışı
  - UML activity diagram format

- **USE_CASE_DIAGRAM.md** — Use case diyagramı (8.2 KB)
  - Sistem kullanıcıları ve rolleri
  - Kullanım senaryoları
  - Actor-system etkileşimleri

- **VERI_MODELLEMESI.md** — Veri modeli belgesi (21 KB)
  - PatientProfile şeması
  - KÜB veri yapısı
  - Database tablolar ve ilişkiler
  - API veri modelleri

## Kullanım

### Sunumlara Erişim

1. **Stakeholder Sunumu:** TEKNIK_SUNUM.md veya TEKNIK_SUNUM_SLIDES.html
2. **Klinik Ekip:** TEKNIK_SUNUM.md (medikal açıklamalar bölümü)
3. **Geliştirici Dokümanı:** VERI_MODELLEMESI.md + DIAGRAMLAR_VISUALIZATION.html

### Diyagramları Açma

- **Markdown diyagramlar:** GitHub'da doğru render edilir, yerel editor'de markdown desteği gerekli
- **HTML diyagramlar:** Herhangi bir web tarayıcısında açılabilir (internet bağlantısı gerekmez)
