ROOT CAUSE ANALYSIS
================================================================================

HAIKU'S MATCHING ALGORITHM (Strict):
  1. Extract claims from answer: e.g., "CYP3A4 inhibition → affects warfarin"
  2. Search chunks for VERBATIM support of each claim
  3. If no exact match → claim not recalled

  Example gap: Chunks say "klaritromisin etkileşimi" (interaction)
               Answer says "CYP3A4 inhibisyonu" (mechanism)
               → "CYP3A4" not in chunk → not recalled (R=0)

MISTRAL'S MATCHING ALGORITHM (Lenient):
  1. Extract claims from answer
  2. Check if chunks are THEMATICALLY RELEVANT
  3. If chunks address the same topic → partially recalled

  Example match: Chunks say "klaritromisin" + "warfarin" + "etkileşimi"
                 Answer addresses same interaction
